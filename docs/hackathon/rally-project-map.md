# Rally project map (Excalidraw)

A study board of Rally — the primitive, the two shapes, the user path, the money rail, the vault state machines, the honest trust model, and the 3-minute pitch.

**File:** [`rally-project-map.excalidraw`](./rally-project-map.excalidraw)

## Open it

1. Go to [excalidraw.com](https://excalidraw.com)
2. Menu (☰) → **Open** → pick `rally-project-map.excalidraw`
3. Or drag the file onto the canvas

Ten frames sit in a row. Zoom out, then click a frame in the sidebar (or double-click a frame title) to focus it.

| Frame | What it's for |
| --- | --- |
| 0 How to read this | Index |
| 1 The primitive | What Rally is, and is not |
| 2 Two shapes | Goals vs Circles |
| 3 What the user sees | Email → amount → done |
| 4 Invisible spine | Magic · 7702 · ZeroDev · CCTP · vaults |
| 5 Money rail | Burn → Iris → mint |
| 6 Goals machine | Active / Succeeded / Failed + relayer bounds |
| 7 Circles machine | Invites → rotate or Broken |
| 8 Trust & keys | Who can do what |
| 9 Proof + pitch | Friday 3-minute run-of-show |

Nothing is locked. Rearrange, restyle, delete boards you don't want in the pitch.

Regenerate after edits to the generator:

```bash
python3 docs/hackathon/generate-rally-map.py
```
